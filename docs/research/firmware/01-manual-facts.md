- 监控接口小结【推断】：对外监控/数采的现实通道=**以太网 Modbus TCP（从站 502，D 区直映，无需任何组态即可读）**，其次 OPC UA/FINS；串口 RS485 Modbus RTU 需组态且本体仅 1 路；Type-C 只服务 AutoShop 私有协议，第三方不可直接使用。

## 2. 固件升级机制全部细节（编程手册附录 26.2-26.3，p961-971；Easy手册 p121-122）

- 两个不同操作，边界明确【手册】：
  - **固件烧录**（26.2，p961-970）：刷整机系统镜像，**完成后原有应用程序被删除**。两条路径：① USB——AutoShop 菜单"工具>固件烧录"，选烧录文件（**文件需向汇川技术人员获取，扩展名未公开**），插/拔 USB 线触发确认；**该功能仅 Easy 系列支持**，多开 AutoShop 时只允许一个实例烧录。② SD 卡——用 **PhoenixCard** 制卡（选择"MLO"文件并全选烧录内容、"量产卡"+"烧卡"，p962-969），卡插 GE20-TF 装入 B 槽上电自动烧；LED 判据：RUN+ERR 快闪 3s=开始，双灯常亮=进行中，慢闪=完成（p970；Easy手册 p122 同）。烧录文件按机型族分两个（Easy30X/32X/50X 一个、Easy52X 一个，p961）。
  - **固件升级**（26.3，p970-971）：AutoShop 菜单"工具>固件升级"，选固件版本文件、**输入验证码**、点"升级"，弹"升级成功"即完成；**完成后原有应用程序保留**。通道：Easy 系列支持**以太网和 USB**，H5U 仅以太网。
- 失败恢复【手册】：烧录/升级中**严禁断电**——断电"可能导致 PLC 无法启动和正常使用"；可**重新执行 SD 卡固件烧录**挽救，仍失败则**返厂维修**（p962、p970-971）。MFK 菜单错误码 E1-E5（非安全状态/无卡/多文件/文件异常或机型不符/密码错，p864-865）与数码管 Er 代码交替显示（p865）——注意 MFK+数码管为 H5U 面板件，**Easy521 面板无数码管/MFK**（部件说明 p102-103），其 SD 烧录为上电自动触发（Easy手册 p121）。
- 与"程序上下载"的边界【手册】：程序层走 PLC>下载/上载、Down 文件（*.down，可含源码、密码、保持型变量属性，p972-977）、Updown 文件（*.updown，可回开编辑，仅 updown 能上载，p977-983）、SD 卡 PLCProgram 目录（STOP 状态才可 SD 升级 Down 文件，密码错报 E5，p973）——这些只动用户工程，不动系统固件；**固件升级动系统但保留工程；固件烧录动系统且清空工程**。
- 【推断】对 WSL 工具链的含义：固件操作全部封装在 AutoShop（Windows）+ PhoenixCard/汇川私有文件内，文件格式与验证码机制未公开，WSL 侧无需也无法涉及。

## 3. 内部系统线索（对照"实测 Allwinner sunxi + Linux 3.10.65"）

- 【手册】**两本手册对 SoC 型号、CPU 架构、内部操作系统均零记载**。全文检索 Linux/ARM/Cortex/sunxi/Allwinner/内核/嵌入式：唯一"Linux"出现在 OPC UA 章的跨平台宣传语中（"支持 Windows、Linux、Mac OS 等多种操作系统"，p581），与 PLC 内部无关；"操作系统"命中均在 AutoShop 安装环境要求（Windows，p35-39）。
- 【手册】可间接佐证嵌入式系统的痕迹仅两处：① SD 制卡用 **PhoenixCard** 工具 + **MLO** 引导文件（p962-963）——MLO 命名是 TI/Allwinner 系 SoC 的 x-loader 惯例，PhoenixCard 是常见 Allwinner 镜像烧写工具【推断：与实测 Allwinner 平台吻合，但手册未点破】；② 系统变量只暴露应用层信息（`_Ethernet.*`、`_SYS_INFO.*` PLC 运行信息 p143、`_MbTcpSlv.*` p136），无任何 shell/OS 层接口。
- 【手册】诊断/调试手段全清单：面板指示灯（PWR/RUN/ERR/ETH1/ETH2/IN/OUT，p863-864）；软件诊断=监控模式下读 PLC 基本信息、故障诊断对话框、错误代码列表 Er****（24.2-24.3，p865-867）；Trace 监控与数据记录（4.11-4.12，p75-85，应用层）；固件版本经 AutoShop 连接查询（【档案】实测返回 Easy521/6.11.0.1）。**无系统日志、串口控制台、telnet/ssh、root 等任何记载**（关键词全文检索为零）。
- 【结论】手册既不印证也不否认 Allwinner+Linux——它把内部完全封装；能佐证的只有 MLO/PhoenixCard 的引导流程痕迹【推断】。
