# Easy521：官方文档允许的直接控制路线

本轮只读本机官方手册和仓库文件，未执行 Windows 程序、访问 GUI/USB/PLC、联网或改应用。讨论型号为现有 **Easy521/Easy52X**；用户新写的 Easy512 型号尚未确认，不把本文能力外推到该型号。逐项证据和归档变量列表见 [JSON 台账](13-documented-control-routes-2026-10-18.json)。

**若目的是从 Linux 直接读写已定义的内存或给已有程序下业务命令，文档中最短的路线是 Modbus TCP。若目的是把任意 ST 变成新的 PLC 应用，这三个数据协议都没有在所查实现章节提供相应契约。** 私有 `g_*` 变量、逻辑输出影像、CPU RUN/STOP、下载应用是四种不同能力。

## Modbus TCP：最短的内存访问路线

P428明确：标准 Modbus TCP 从站/服务器默认开启，无需额外选择通信协议，端口 **502**，最多31客户端。主机仍须知道实际 PLC IP，建立以太网链路并成功访问服务。这里是**手册默认行为**，不是当前设备的监听验证；本轮没有读取当前 IP、监听状态或工程配置。

P428支持 `01/02` 读位、`03/04` 读字、`05` 写单个位、`06` 写单字、`0F` 写多个位、`10` 写多个字；手册将02描述为同01、04描述为同03。以下均为报文中的原始地址偏移，不是软件显示的40001等编号。

| 区域 | 软元件范围 | Modbus 原始地址范围（十进制） |
| --- | --- | --- |
| 位 | M0–M7999 | 0–7999 |
| 位 | B0–B32767 | 12288–45055 |
| 位 | S0–S4095 | 57344–61439 |
| 位 | X0–X1777，X编号八进制 | 63488–64511 |
| 位 | Y0–Y1777，Y编号八进制 | 64512–65535 |
| 字 | D0–D7999 | 0–7999 |
| 字 | R0–R32767 | 12288–45055 |

因此 D100 对应读字功能的偏移100，M100对应位功能的偏移100；Y0对应位地址 `0xFC00`/64512。P429明确不支持W和Pointer变量。

这张表证明默认软元件区的协议映射，不证明自定义名称已经绑定这些软元件。它也没有逐区给出写权限、物理输入强制规则、输出保持或与扫描程序竞争时的优先级。Y区及写功能码是直接访问输出影像的文档入口，**不能把“写入Y影像”立即等同“端子一定按此持续输出”**。实际硬件还受供电、接线、CPU状态、I/O配置及用户逻辑影响；本轮未写任何X/Y。

P425–427的“禁用Modbus TCP从站”使用 `_MbTcpMstEx[N].SlvDisable...`，用于本PLC作为主站时禁用某个远端从站，不能误当作关闭本机502服务器的配置证据。

## FINS：支持数据读写，但不要套用其他PLC的CPU命令

P433明确 H5U&Easy仅作为 FINS TCP/UDP 从站，标准服务默认开启，端口 **9600**，TCP最多32客户端。P434的本机实现命令表列出：

- `01 01`：连续I/O内存读取。
- `01 02`：连续I/O内存写入。

所有区域均映射到 **DM字地址**：

| 区域 | 软元件范围 | FINS DM字地址（十进制；十六进制） |
| --- | --- | --- |
| D | D0–D7999 | 0–7999；`0000–1F3F` |
| R | R0–R19999 | 8192–28191；`2000–6E1F` |
| X | X0–X1777，八进制 | 28416–28479；`6F00–6F3F` |
| Y | Y0–Y1777，八进制 | 28496–28559；`6F50–6F8F` |
| M | M0–M7999 | 28672–29171；`7000–71F3` |

X/Y/M按16个位打包成一个字。写DM `0x7000`涉及M0–M15；写DM `0x6F50`涉及Y0–Y7及Y10–Y17（编号八进制），不能将其当单个布尔量写入。地址区有间隔，不应跨区连续访问；最大连续数量2000字，节点/IP末字节限制254。

**P434明确FINS UDP要求PLC已经处于RUN。** 这不是可以从STOP启动CPU的依据。TCP在STOP下的具体可用性没有由该条说明建立，需另行观察。所查实现表没有证明其他品牌常见的CPU RUN/STOP命令在Easy521上已实现，不能直接照搬其他FINS设备命令。

## OPC UA：直接使用变量名，但必须先发布变量

P625要求在工程中勾选激活OPC UA服务器；P626默认端口 **4840**，可配置1024–49151内且避开列出的专用端口。不能只因有默认端口就断定当前服务器已经激活。支持条件明确包含Easy固件6.3.0.0及以上、AutoShop4.10.1.0及以上；后续增强另有版本要求。

P624、629给出关键权限：私有全局变量不注册、不可读写；“公有”和“输入/输出”全局变量注册后可读写。P623描述数组/结构成员访问，P624同时限制公开变量最多2000个、基本元素合计20000个，并对较新数组/结构功能列出额外版本门槛。P626中Easy52X最大会话数20，最短采样档100ms；这不是5ms逐扫描监控保证。

**P622明确：已经运行的OPC UA服务器在PLC切到STOP后保持运行。** 因此P90概述中的“STOP时通信停止”不能被扩展为所有网络服务必然关闭。服务器启停还与工程激活设置、下载、Stop/Run和 `OPCUA_Server_Shutdown` 等条件有关，不能仅据CPU状态猜测端口。

P627–628描述安全策略和身份认证，配置项默认勾选匿名登录；这不是本设备当前允许匿名访问的实测结论。OPC UA的一般性介绍提到方法/服务，不能据此宣称Easy521已经公开CPU RUN/STOP或ST下载方法；所查设备配置章节建立的是变量读写能力。

## CPU控制、供电与应用下载的边界

P90列出的CPU模式切换方式是物理RUN/STOP开关和AutoShop工具栏。P168将M8000标为只读运行标志，M8001为其取反，M8002为首运行扫描标志。默认Modbus/FINS的M映射均只到M7999，**不能把M8000猜成可写的“启动CPU线圈”**。

已有运行程序可以把某个M/D变量解释成业务START、模式或参数：这是应用接口设计，程序需要有相应逻辑并实际扫描。这种START不是CPU RUN，也不产生新的控制算法。所查三种协议的本机实现章节没有给出普通ST输入、项目预处理、链接封装、应用传输及设备端程序身份读回契约。结论是“文档尚未建立任意ST下装能力”，不是断言任何厂商扩展都不可能。

U139规定Easy52X主电源为24VDC±10%（21.6–26.4V），U140–141给出相同的物理I/O电压等级；U138明确以太网接口不支持PoE。U138也明确讨论USB单独供电，限制为不支持掉电保持；U139列出Type-C程序上下载和固件升级。**这些页没有明确规定USB-only时CPU/以太网的全部运行能力，不能据此判定当前RUN失败根因，也不能反向保证USB可支持正常I/O运行。** 普通网线连接不是主电源。

P420的192.168.1.88和MFK复位说明专指H5U，不能预填为Easy521实际或出厂IP。Type-C的厂商用途有文档，第三方“永远不可用”的结论没有被这些手册证明。

## 现有BESS项目为什么不能直接套D0–D17

已重新逐行读取仓库 [原生导入表](../../../plc/easy521/autoshop_global_import.csv)、[变量清单](../../../plc/easy521/MAIN_5ms_variables.csv)、归档DEV的UTF-16 `VarNameAndAddr.csv` 及 [REAL32协议设计表](../../../plc/easy521/modbus_register_map_real32.csv)：

- 19个 `g_*` 全局变量的“软元件地址”均为空，“网络公开”均为私有。
- 归档符号表给出 `0x210...` 内部符号位置。这些位置不是已证明的D号、Modbus地址或可直接寻址的芯片物理内存。
- 协议CSV设计了D0–D13测量值与D14–D17命令值，但它不是厂商变量绑定记录；其中ABCD字序也不是本轮设备已验证结果。

P123–124说明真正的名称绑定步骤：在变量表地址栏填软元件地址并编译；BOOL绑定位元件，INT占一字，DINT/REAL占连续两字。这些归档文件没有完成该绑定的证据，也没有发布到OPC UA的证据。以上只评价仓库归档，不冒充当前设备最新变量表。

因此可评估的最简方案是：在确认真实IP/服务后先用Modbus读取一小段已知D/M内存；如需控制BESS，再一次性建立明确、可检查的命令/状态地址接口或发布UA变量。此后Linux可以直接读写业务参数；任意改ST并部署新的应用仍走独立的编译/下装路线。本报告没有执行上述试验。
